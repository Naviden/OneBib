# OneBib 1.0.0

OneBib brings a small, local-first citation workflow to Obsidian. Point it at one `.bib` file and cite an entry with `>>citationKey<<`; OneBib renders an author–year citation and maintains the note's References section.

## Highlights

- Works entirely inside the vault with no account, network service, or telemetry.
- Renders citations in Live Preview and Reading view.
- Completes citation keys by key, author, or title after typing `>>`.
- Provides a searchable **Insert citation** command.
- Generates an alphabetized, APA-like References section containing only cited works.
- Supports grouped citations such as `>>firstKey; secondKey<<`.
- Refreshes citations and references after the selected `.bib` file changes.
- Runs on desktop and mobile Obsidian 1.5.0 and later.

## Installation

Download `onebib-1.0.0.zip` and extract it into `<vault>/.obsidian/plugins/onebib/`, or download `main.js`, `manifest.json`, and `styles.css` into that directory. Enable OneBib under **Settings → Community plugins**.

This is the first release. Please report parsing or formatting edge cases through GitHub Issues.
